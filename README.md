# Teams 实时翻译字幕工具

> 状态：待开发 / 方案确认中  
> 平台：Windows 10/11   
> 第一版方向：采集电脑播放的 Teams 会议声音，在本机完成语音识别和翻译，并实时显示双语字幕。

## 项目目标

制作一个本地桌面辅助工具，帮助用户在 Teams 会议期间查看口语内容的原文转写和目标语言翻译。第一版以系统播放音频为输入，不要求开启 Teams 官方会议录制或转录功能。

## 使用边界

- 仅在用户明确启动后采集，界面持续显示采集状态，并提供暂停和停止按钮。
- 使用前由用户确认组织政策及会议参与者的知情、同意要求。
- 不绕过 Teams 权限、组织策略或访问控制，不做隐藏采集。
- 默认本机处理，不保存原始音频；字幕记录是否保存应由用户明确选择。
- 如后续接入云端服务，必须单独提示哪些音频或文本会发送到哪个服务。

## 第一版功能范围

1. 选择音频来源：优先评估只采集 Teams 进程音频；提供系统播放设备回环作为兼容选项。
2. 开始、暂停、继续和停止采集；显示音频设备和采集状态。
3. 对音频做分段与语音活动检测，实时生成临时字幕，并在停顿后定稿。
4. 显示时间戳、原文、译文和识别状态；支持设置源语言、目标语言、字体大小及字幕窗口位置。
5. 默认不保留原始音频；允许用户选择是否导出字幕文本或 SRT 文件，并可清除会话内容。

## 技术方向

- 桌面界面：C# / .NET 桌面应用。
- 音频采集：Windows WASAPI 回环；先验证按应用进程采集 Teams 的可行性，并保留常规设备回环作为后备方案。
- 语音识别：本机模型，按短音频片段持续推理；保留少量重叠音频以减少切片处漏字。
- 翻译：本机文本翻译模型；识别定稿后翻译，避免不断翻译临时识别结果。
- 字幕呈现：置顶、可调整透明度和字体的字幕窗口；原文与译文并排或上下显示。

## 实施阶段

### 阶段 1：音频采集验证

- 枚举 Windows 播放设备。
- 验证 WASAPI 回环采集和音频格式转换。
- 验证按应用进程采集 Teams 的兼容性；记录不支持时的提示和后备路径。
- 确认开始、暂停、停止状态可靠，停止后释放音频资源。

### 阶段 2：实时语音识别

- 建立音频缓冲、语音活动检测和分段策略。
- 输出带时间戳的临时字幕与最终字幕。
- 观察常见会议中的延迟、漏字、重复字和断句问题。

### 阶段 3：翻译与字幕界面

- 接入本机翻译流程。
- 实现双语字幕窗口、语言选择、字体设置、置顶和可拖动位置。
- 处理静音、设备切换、模型繁忙和识别失败等状态。

### 阶段 4：导出与打包

- 提供会话记录的选择性保存、文本/SRT 导出和清除。
- 完成本机安装包与首次运行指引。
- 在用户确认组织许可后再进行真实会议试用。

## 验收标准（第一版）

- 可启动并停止音频采集，状态清晰可见。
- 可对测试会议音频连续显示原文和译文字幕，并包含时间戳。
- 停止采集后不继续读取音频，默认不留下原始录音。
- 设备不可用、识别失败或模型延迟时，界面显示明确状态，不静默丢失。
- 用户可选择导出字幕或清除本次内容。

## 主要风险与限制

- 系统回环模式可能捕获同一播放设备上的其他应用声音；按应用采集的支持情况需在目标 Windows 版本上实测。
- 本机识别与翻译的速度取决于电脑 CPU/GPU、模型大小和语言组合。
- 重叠发言、口音、背景噪声、专有名词与数字会影响识别质量；译文需可回看原文。
- 本项目是辅助字幕，不应将自动识别结果视为准确会议纪要。

## 当前待确认项

- 第一版目标语言是否默认为中文。
- 是否要求严格离线（包括模型下载后运行时不联网）。
- 是否需要保存会话字幕，以及默认保存时长。
- 用户电脑的 Windows 版本、内存和显卡信息，用于选择可实时运行的本地模型。
